# 심리교육 숏폼 편집 — 작업 인수인계

> 클라우드 세션에서 분석한 내용을 `클로드 코드_HR` 폴더(로컬 PC)에서 이어가기 위한 문서입니다.
> 이 파일을 그 폴더에 복사한 뒤, 아래 **"새 세션 시작 프롬프트"**를 Claude Code에 붙여넣으세요.

## 1. 목표

유튜브 심리교육 채널(심리이론 설명 + 강의 현장 영상)을
레퍼런스 릴스(lazy_owen, 2026-08-11 화면녹화)와 같은 **상단 자료 + 하단 화자 2단 분할 숏폼**으로 편집.
일회성 편집이 아니라 **재사용 가능한 파이프라인**(원본 + 자막 텍스트 → 렌더링)으로 만든다.

### 레이아웃

```
┌─────────────────────┐
│  파스텔 그라데이션 배경   │  복숭아/핑크/노랑 계열, 컷마다 색 변함
│  ┌───────────────┐  │
│  │   B롤 카드       │  │  상단 약 45%, 라운드 모서리 + 드롭섀도로 떠 있는 느낌
│  └───────────────┘  │
│   자막 한 줄          │  두 영역 경계선에 걸침
│  ┌───────────────┐  │
│  │   화자(토킹헤드)   │  │  하단 약 55%, 위쪽 모서리만 라운드, 화면 아래로 블리드
└──└───────────────┘──┘
```

- 일부 컷은 화자 풀스크린(강조 포인트), 일부는 B롤 풀스크린(오프닝 훅, 타이틀 카드)
- 오프닝 0~3초: B롤 풀스크린 + 자막으로 훅
- 엔딩: 댓글 UI 목업 + CTA ("댓글에 '영상'이라고 남겨주세요")

### 자막 스타일

- 폰트: 극태 한글 산세리프 → **Pretendard Black** 로 재현
- 흰 글자 + 두꺼운 검정 외곽선 + 약한 그림자
- 한 컷에 짧은 구절 한 줄 (8~14자)
- **핵심 단어 1개만 노란색**(#FFD400 근처) 하이라이트
- 가로 중앙 정렬, 1080px 폭 기준 글자 크기 약 70px

## 3. 심리교육 콘텐츠 매핑

| 레퍼런스 | 선생님 콘텐츠 |
|---|---|
| 상단 B롤 (앱 화면녹화) | 이론 도식, 실험 장면, 그래프, 인용 카드, 도서 표지 |
| 하단 토킹헤드 | 강의 현장 영상 (보유) |
| 노란 키워드 | 이론 용어 — 방어기제, 인지부조화, 애착유형 등 |
| 엔딩 CTA | "댓글에 '교안'이라고 남기면 자료 보내드려요" 등 |

## 4. 기술 스택 (클라우드에서 검증 완료)

- **ffmpeg**: 합성 전부 담당. 필요한 필터 `subtitles`/`ass`(키워드 색상), `overlay`, `gblur`, `geq`, `drawbox` 모두 동작 확인
  - Windows: `winget install Gyan.FFmpeg`
  - `drawtext`가 없는 빌드도 있으므로 자막은 **ASS 파일**로 처리 (인라인 색상 태그 `{\c&H00D4FF&}영상{\c&HFFFFFF&}`)
- **폰트**: Pretendard v1.3.9 — https://github.com/orioncactus/pretendard/releases (`Pretendard-Black.otf`, `Pretendard-ExtraBold.otf`)
- **자막 타이밍**: 음성인식이 필요 → 로컬에서 `whisper`(openai-whisper 또는 faster-whisper) 설치, 또는 대본 + 수동 타임코드
- **B롤 이미지**: 이론 도식은 이미지 생성 도구 또는 직접 만든 슬라이드 PNG

## 5. 남은 작업 (순서대로)

1. [ ] 강의 원본 영상 1개 + 해당 구간 대본 준비
2. [ ] 레이아웃 프로토타입: 그라데이션 배경 + B롤 카드 + 화자 카드 + ASS 자막 합성 스크립트
3. [ ] 키워드 하이라이트 규칙: 대본에서 `[[키워드]]` 표시하면 노란색으로 변환
4. [ ] 컷 리스트 형식 정하기 (CSV: 시작, 끝, 레이아웃종류, 자막, B롤파일)
5. [ ] 샘플 1편 렌더링 → 검토 → 스타일 조정
6. [ ] 반복 사용용 스크립트/서브에이전트로 정리
